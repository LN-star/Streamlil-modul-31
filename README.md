# CSV‑Анализатор на Streamlit
Интерактивное приложение для анализа произвольных CSV‑файлов.
Позволяет быстро исследовать данные, строить графики, вычислять статистику и визуализировать распределения — всё прямо в браузере.

### 📝 Описание
Этот проект создан для удобного анализа табличных данных без необходимости писать код.
Приложение автоматически обрабатывает числовые, текстовые и временные столбцы, строит графики и вычисляет ключевые статистические показатели.

Функциональность включает:

📁 загрузку CSV‑файла с автоматическим определением кодировки

📄 отображение таблицы в интерактивном виде

🎛 выбор столбцов для анализа

📈 статистику по числовым данным:
- среднее
- медиана
- стандартное отклонение

📉 построение графиков:
- линейный
- диаграмма рассеяния

📊 построение гистограммы распределения

💾 скачивание построенного графика

🕒 корректная обработка дат и времени

⚡ кеширование для ускорения работы

### Используемые алгоритмы:
- Среднее: Код mean = sum(x) / n
- Стандартное отклонение: Код std = sqrt(sum((x - mean)^2) / n)
- Медиана — центральное значение отсортированного ряда.

### ⚙️ Установка зависимостей
Убедитесь, что установлен Python 3.9+.
1. Клонируйте репозиторий:
`git clone https://github.com/USERNAME/REPOSITORY.git
cd REPOSITORY`

3. Создайте виртуальное окружение (по желанию):
`python -m venv venv`

Активация:

`venv\Scripts\activate      # Windows`

`source venv/bin/activate   # Linux/Mac`

3. Установите зависимости:

`pip install streamlit pandas numpy matplotlib`

### 🚀 Запуск
Выполните команду:
`streamlit run app.py`

После запуска приложение откроется в браузере.
Если не открылось автоматически, перейдите по адресу:
`http://localhost:8501`
